# hello-action-shortcut

Starts the built app through the remote control server, presses Ctrl+Shift+H (Cmd+Shift+H on macOS), the shortcut of the Hello menu's Say Hello From an Action, as a user would, through the native app, and checks the line the action's handler shows. On a mobile it checks nothing, because a mobile has no shortcuts.

It takes no arguments. Run it with:

```
bun run test:smoke -- hello-action-shortcut
```

See [the run documentation](../run.md).
